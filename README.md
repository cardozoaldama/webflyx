# Webflyx Git Exercise

A simple practice repository from the [Boot.dev](https://www.boot.dev) Back-End course.

## Topics Covered

This repository covers the basics of Git:

- Staging, committing, and resetting
- Local and remote repositories
- System, global, and local configurations
- Amending commits (`git commit --amend`)
- Branching with `git switch` and `git checkout`
- Restoring the staging area and working directory with `git restore`
